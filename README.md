### Currently building — [Frezpo](https://frezpo.com/)

**Frezpo** turns one client brief into a matched Google Ads + landing page strategy pack —
ad architecture, landing page strategy, and design tokens generated together, so the ad's
promise and the page's headline never drift apart.

The problem it targets is **message match**: the gap between what an ad promises and what
the landing page delivers. High click-through with a high bounce rate is almost always this
gap, and it opens because the ads and the page get written by different people, at different
times, from different briefs.
